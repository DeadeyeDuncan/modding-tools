## Global Constraints

- **Python 3.13, stdlib only.** No pip installs. Run via `py -3` (never the bare `python` Store alias — reflection-notes §3).
- **External processes allowed:** `BSArch64.exe` (BSA listing/packing) and `Texconv.exe` (DDS decode) ONLY, paths read from `modkit.json` (`forensics.tools.*`), never hardcoded in tool code (SSD/multi-machine portability rule).
- **READ-ONLY against game dirs.** No forensics tool ever writes, moves, renames, or deletes anything under the game root or `Data\`. Tools report; quarantine/restore/fix actions stay manual or in modkit. `esp_tools.py gut` writes its stub to a caller-supplied path and REFUSES a destination under the configured `dataDir`.
- **All config from `modkit.json`** at `C:\Modding\tools\modkit.json`, loaded through `modkit.config` (delegation in `_lib.load_config`). The only hardcoded path in the kit is the repo-relative location of `modkit.json` itself (`TOOLS_ROOT / "modkit.json"`, derived from `__file__`).
- **Tests use synthetic fixtures only** — byte-built ESP/NIF binaries from `tests\test_forensics\fixtures.py`, temp-dir Data trees, fixture configs. No test reads or writes the real game dirs, real ledger, or real Plugins.txt. The one real-artifact exception: the tiny BSA fixture is **generated by BSArch itself** from fixture loose files in a temp dir (Task 2), because a hand-built BSA would re-import the exact parser-bug class this kit exists to kill.
- **PowerShell 5.1 syntax rules** for the two `.ps1` tools: no `&&`/`||` chain operators, no ternary/null-coalescing, `-LiteralPath` for mod paths, `-Encoding utf8` on `Out-File`, no Unicode glyphs in output (cp1252-safe), param blocks with defaults, no `Read-Host`.
- **Console output ASCII-safe** (cp1252 console; ledger.py precedent).
- **Cache/report writes are atomic** (temp file + `os.replace`) and live under `forensics.cacheDir` from modkit.json — never under the game root.
- **Binary-format discipline:** byte offsets and flags used in code are either (a) established by the wiki/memory evidence (cited inline in the task) or (b) marked `ASSUMED` in code comments with an explicit verify-on-machine checkbox step against a named real file before the parser is trusted. Never silently invent format constants — an inline BSA parser's offset bug cost hours of false-positive triage (reflection-notes §6, session `3a7247b5`).
- **One commit per task**, directly to `master` (repo convention per `docs\2026-07-11-BUILD-ORDER.md`; run this build alone, after modkit merges).
- Full suite must stay green at every commit: `py -3 -m unittest discover -s C:\Modding\tools\tests` (includes the pre-existing `test_ledger.py`).

- [ ] **Step 5: Write the fixture builders**

Create `C:\Modding\tools\tests\test_forensics\fixtures.py`. These byte-level builders are shared by Tasks 1, 3, 4, 5, 7. Layout constants marked ASSUMED are standard TES5 layout not yet pinned by wiki evidence; Task 4 Step 9 verifies them against real files before the parsers are trusted.

```python
"""Byte-level fixture builders for the forensics test suite.

ESP record-header layout used here (24 bytes):
    type[4] + dataSize u32 + flags u32 + formID u32 + vc u32 + version u16 + unknown u16
dataSize@4 and the 24-byte header are wiki-established
(concepts/skyrim-gut-plugin-to-header-only: "dataSize = ToUInt32(bytes, 4)";
complete TES4 record = first 24 + dataSize bytes).
flags@8 / formID@12 / compressed-flag 0x00040000 / GRUP size-includes-header /
subrecord u16 size are ASSUMED standard TES5 layout — verified on-machine in
Task 4 Step 9 before any real-plugin verdict is trusted.
"""
import struct
import zlib

FLAG_COMPRESSED = 0x00040000  # ASSUMED - verify Task 4 Step 9
FLAG_ESL = 0x200              # modkit design doc (ESL flag 0x200)


def zstring(s):
    return s.encode("cp1252") + b"\x00"


def sub(stype, payload):
    """Subrecord: 4-char type + u16 payloadSize + payload (ASSUMED u16 size)."""
    assert len(stype) == 4
    return stype.encode("ascii") + struct.pack("<H", len(payload)) + payload


def record(rtype, formid, subrecords, flags=0, compressed=False):
    data = b"".join(subrecords)
    if compressed:
        raw_len = len(data)
        data = struct.pack("<I", raw_len) + zlib.compress(data)
        flags |= FLAG_COMPRESSED
    hdr = (rtype.encode("ascii") + struct.pack("<I", len(data))
           + struct.pack("<I", flags) + struct.pack("<I", formid)
           + struct.pack("<I", 0) + struct.pack("<HH", 44, 0))
    return hdr + data


def grup(label4, records_bytes):
    """GRUP header is 24 bytes; groupSize INCLUDES the header (ASSUMED)."""
    contents = b"".join(records_bytes)
    return (b"GRUP" + struct.pack("<I", 24 + len(contents)) + label4
            + struct.pack("<i", 0) + struct.pack("<I", 0) + struct.pack("<I", 0)) + contents


def tes4_record(masters, esl=False):
    subs = [sub("HEDR", struct.pack("<fIi", 1.71, 0, 0x800))]
    for m in masters:
        subs.append(sub("MAST", zstring(m)))
        subs.append(sub("DATA", struct.pack("<Q", 0)))
    return record("TES4", 0, subs, flags=(FLAG_ESL if esl else 0))


def build_esp(masters, stats, esl=False, compressed_formids=()):
    """Build a minimal plugin: TES4 header + one STAT GRUP.

    stats: list of (formid, edid, modl_path_or_None).
    """
    recs = []
    for formid, edid, modl in stats:
        subs = [sub("EDID", zstring(edid))]
        if modl is not None:
            subs.append(sub("MODL", zstring(modl)))
        recs.append(record("STAT", formid, subs,
                           compressed=(formid in compressed_formids)))
    out = tes4_record(masters, esl=esl)
    if recs:
        out += grup(b"STAT", recs)
    return out


def build_nif(texture_paths, extra=b"", junk=b"\x00\x01NiNode\x00\xff"):
    """Nif-LIKE bytes: binary noise with embedded ASCII texture paths.

    The extractor (Task 3) is a byte-level string scan — exactly the method the
    wiki proved load-bearing (grep -a over .nif) — so fixtures only need real
    ASCII paths inside binary noise, not a structurally valid NIF.
    """
    parts = [b"Gamebryo File Format, Version 20.2.0.7\n", junk]
    for t in texture_paths:
        parts.append(struct.pack("<I", len(t)) + t.encode("cp1252") + b"\x00\xfe")
    parts.append(extra)
    return b"".join(parts)
```

```python
def atomic_write_text(path, text):
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=str(path.parent), suffix=".tmp")
    try:
        with os.fdopen(fd, "w", encoding="utf-8", newline="\n") as f:
            f.write(text)
        os.replace(tmp, path)
    except BaseException:
        if os.path.exists(tmp):
            os.unlink(tmp)
        raise
```

```python
def parse_bsarch_listing(text):

    The tiny-BSA round-trip test is the authority that this parse is complete."""

        if m:

    return [name for name, paths in index["bsas"].items() if rel in set(paths)]


def dir_prefixes(index):
    """Every directory prefix present in any BSA — the mod-specific-path signal:
    a miss under a prefix NO BSA carries cannot have a BSA fallback (wiki:
    the only fully reliable genuine-hole signal)."""
    out = set()
    for paths in index["bsas"].values():
        for p in paths:
            parts = p.split("\\")[:-1]
            for i in range(1, len(parts) + 1):
                out.add("\\".join(parts[:i]))
    return out


def raw_confirm(bsa_path, name, chunk=1 << 24):
    """Case-insensitive byte scan of the BSA for a filename — the wiki's
    reliable confirmation for vanilla paths the structured index may miss
    (grep -a equivalent; used 6+ times in session dba84d3e)."""
    needle = _lib.norm_rel(name).split("\\")[-1].encode("cp1252", "replace").lower()
    if not needle:
        return False
    keep = len(needle) - 1
    carry = b""
    with open(bsa_path, "rb") as f:
        while True:
            block = f.read(chunk)
            if not block:
                return False
            hay = (carry + block).lower()
            if needle in hay:
                return True
            carry = block[-keep:] if keep else b""

    s = sp.add_parser("stats")
    s.add_argument("--game", default="skyrim")
    s.add_argument("--config", default=None)
    s.add_argument("--index", default=None)
    args = ap.parse_args(argv)

    if args.cmd == "build":
        index = build_index(cfg, args.game)
        out = Path(args.out) if args.out else default_index_path(cfg, args.game)
        _lib.atomic_write_json(out, index)
        total = sum(len(v) for v in index["bsas"].values())
        _lib.say("wrote %s (%d BSAs, %d entries)" % (out, len(index["bsas"]), total))
        return 0
    idx_path = Path(args.index) if args.index else default_index_path(cfg, args.game)
    if not idx_path.is_file():
        raise _lib.ForensicsError("no index at %s - run: bsa_index.py build" % idx_path)
    index = load_index(idx_path)
    if args.cmd == "stats":
        for name in sorted(index["bsas"]):
            _lib.say("%-40s %6d" % (name, len(index["bsas"][name])))
        _lib.say("TOTAL %d entries" % len(all_paths(index)))
        return 0
    # query
    rel = _lib.norm_rel(args.name)
    hits = contains(index, rel)
    if hits:
        for h in hits:
            _lib.say("INDEX-HIT %s :: %s" % (h, rel))
        return 0

                 for p in paths if p.endswith("\\" + base) or p == base]
```

```python
"""nif_texrefs.py — extract texture paths referenced by .nif files.

Usage:
    py -3 C:\\Modding\\tools\\forensics\\nif_texrefs.py <file-or-dir> [...] 
    py -3 ...\\nif_texrefs.py Data\\meshes\\smim --check      (verify refs vs loose+BSA)
    py -3 ...\\nif_texrefs.py <path> --json out.json

READ-ONLY. Method: byte-level ASCII scan for 'textures\\...*.dds' — the exact
technique proven load-bearing in the sagas (grep -a over .nif settled the
CM-bake family; the 2026-07-01 texture-ref sweep variant: extract every texture
reference from a scoped set of loose meshes, verify each against loose Data +
BSAs — wiki concepts/skyrim-build-wide-missing-mesh-sweep, memory
sse-cmbake-shiny-leftovers). Texture paths live in BSShaderTextureSet blocks;
this tool does NOT parse block structure (not wiki-established) — it reports
the union of texture strings in the file, which is what every recorded use
needed. Verified against NifSkope on a real mesh (Task 3 Step 6).

Safety gate reminder from the wiki: before quarantining anything based on a
MISSING ref, verify BSA fallback for both texture AND mesh.
"""
import argparse
import re
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from forensics import _lib

_TEX_RE = re.compile(rb"(?i)textures[\\/][ -~]{0,240}?\.dds")


def extract_texrefs(data):
    refs = set()
    for m in _TEX_RE.finditer(data):
        refs.add(_lib.norm_rel(m.group(0).decode("ascii", "replace")))
    return sorted(refs)


def check_refs(refs, data_dir, bsa_paths_set):
    data_dir = Path(data_dir)
    out = {}
    for ref in refs:
        if (data_dir / ref).is_file():
            out[ref] = "LOOSE"
        elif ref in bsa_paths_set:
            out[ref] = "BSA"
        else:
            out[ref] = "MISSING"
    return out


def collect_nifs(paths):
    nifs = []
    for p in paths:
        p = Path(p)
        if p.is_dir():
            nifs.extend(ap for ap, _rel in _lib.iter_files(p, exts=(".nif",)))
        elif p.is_file():
            nifs.append(p)
        else:
            raise _lib.ForensicsError("no such path: %s" % p)
    return nifs


def main(argv=None):
    ap = argparse.ArgumentParser(description="NIF texture-reference audit")
    ap.add_argument("paths", nargs="+")
    ap.add_argument("--check", action="store_true",
                    help="classify each ref LOOSE/BSA/MISSING (needs bsa_index build)")
    ap.add_argument("--json", default=None, help="write full report JSON here")
    ap.add_argument("--game", default="skyrim")
    ap.add_argument("--config", default=None)
    ap.add_argument("--index", default=None)
    args = ap.parse_args(argv)

    nifs = collect_nifs(args.paths)
    report = {"meshes": {}, "missing": {}}
    for nif in nifs:
        report["meshes"][str(nif)] = extract_texrefs(nif.read_bytes())

    if args.check:
        from forensics import bsa_index
        cfg = _lib.load_config(args.config)
        data_dir = _lib.game_path(cfg, "dataDir", args.game)
        idx_path = Path(args.index) if args.index else bsa_index.default_index_path(cfg, args.game)
        if not idx_path.is_file():
            raise _lib.ForensicsError("no BSA index at %s - run bsa_index.py build first" % idx_path)
        bsa_paths = bsa_index.all_paths(bsa_index.load_index(idx_path))
        all_refs = sorted({r for refs in report["meshes"].values() for r in refs})
        verdicts = check_refs(all_refs, data_dir, bsa_paths)
        for mesh, refs in report["meshes"].items():
            missing = [r for r in refs if verdicts[r] == "MISSING"]
            if missing:
                report["missing"][mesh] = missing
        for ref in all_refs:
            _lib.say("%-8s %s" % (verdicts[ref], ref))
        _lib.say("scanned %d meshes, %d unique refs, %d MISSING"
                 % (len(nifs), len(all_refs), sum(1 for v in verdicts.values() if v == "MISSING")))
    else:
        for mesh, refs in report["meshes"].items():
            _lib.say(mesh)
            for r in refs:
                _lib.say("    " + r)

    if args.json:
        _lib.atomic_write_json(args.json, report)
        _lib.say("wrote %s" % args.json)
    return 1 if report["missing"] else 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
Record-walk constants: 24-byte record header + dataSize@4 are wiki-established.
flags@8, formID@12, compressed flag 0x00040000 (u32 decomp-size prefix), GRUP
size-includes-header, subrecord type[4]+u16 size, XXXX oversize extension are
ASSUMED standard TES5 layout — verified on-machine (plan Task 4 Step 9) against
Skyrim.esm and SMIM-SE-Merged-All.esp before real-plugin verdicts are trusted.
"""
import argparse
import json
import struct
import sys
import zlib
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from forensics import _lib

REC_HDR = 24
FLAG_COMPRESSED = 0x00040000  # ASSUMED - verify Step 9
FLAG_ESL = 0x200


def iter_records(data, offset=0, end=None):
    end = len(data) if end is None else end
    pos = offset
    while pos + REC_HDR <= end:
        rtype = data[pos:pos + 4]
        size = struct.unpack_from("<I", data, pos + 4)[0]
        if rtype == b"GRUP":
            inner_end = pos + size  # groupSize includes the 24-byte GRUP header (ASSUMED)
            if inner_end > end or size < REC_HDR:
                raise ValueError("malformed GRUP at 0x%X" % pos)
            yield from iter_records(data, pos + REC_HDR, inner_end)
            pos = inner_end
        else:
            if pos + REC_HDR + size > end:
                raise ValueError("record %r at 0x%X overruns file"
                                 % (rtype, pos))
            flags, formid = struct.unpack_from("<II", data, pos + 8)
            yield (rtype.decode("ascii", "replace"), flags, formid,
                   data[pos + REC_HDR: pos + REC_HDR + size])
            pos += REC_HDR + size


def record_payload(flags, raw):
    if flags & FLAG_COMPRESSED:
        decomp_size = struct.unpack_from("<I", raw, 0)[0]
        out = zlib.decompress(raw[4:])
        if len(out) != decomp_size:
            raise ValueError("decompressed size mismatch")
        return out
    return raw


def iter_subrecords(payload):
    pos = 0
    oversize = None
    while pos + 6 <= len(payload):
        stype = payload[pos:pos + 4].decode("ascii", "replace")
        ssize = struct.unpack_from("<H", payload, pos + 4)[0]
        pos += 6
        if stype == "XXXX":  # oversize extension (ASSUMED)
            oversize = struct.unpack_from("<I", payload, pos)[0]
            pos += ssize
            continue
        if oversize is not None:
            ssize, oversize = oversize, None
        yield stype, payload[pos:pos + ssize]
        pos += ssize


def modl_records(path):
    """([(formid, record_type, modl_path)], [parse-error strings]).
    Never crashes a sweep: malformed records are reported, not fatal."""
    data = Path(path).read_bytes()
    out, errors = [], []
    try:
        for rtype, flags, formid, raw in iter_records(data):
            if rtype == "TES4":
                continue
            try:
                payload = record_payload(flags, raw)
                for stype, sdata in iter_subrecords(payload):
                    if stype == "MODL":
                        modl = sdata.split(b"\x00")[0].decode("cp1252", "replace")
                        out.append((formid, rtype, modl))
            except Exception as e:
                errors.append("%s form 0x%08X: %s" % (rtype, formid, e))
    except Exception as e:
        errors.append("walk aborted: %s" % e)
    return out, errors


def gut_stub_bytes(data):
    if data[:4] != b"TES4":
        raise _lib.ForensicsError("not a TES4 plugin (starts with %r)" % data[:4])
    size = struct.unpack_from("<I", data, 4)[0]
    if 24 + size > len(data):
        raise _lib.ForensicsError("TES4 dataSize overruns file - corrupt header")
    return data[:24 + size]


def main(argv=None):
    ap = argparse.ArgumentParser(description="ESP/ESM forensics")
    sp = ap.add_subparsers(dest="cmd", required=True)
    m = sp.add_parser("masters")
    m.add_argument("plugin")
    m.add_argument("--json", action="store_true")
    mo = sp.add_parser("modl")
    mo.add_argument("plugin")
    mo.add_argument("--json", action="store_true")
    g = sp.add_parser("gut")
    g.add_argument("plugin")
    g.add_argument("-o", "--out", required=True)
    g.add_argument("--game", default="skyrim")
    g.add_argument("--config", default=None)
    args = ap.parse_args(argv)

    if args.cmd == "masters":
        info = _lib.tes4_header(args.plugin)
        if args.json:
            print(json.dumps(info, indent=2))
        else:
            _lib.say("esl: %s" % info["esl"])
            for mast in info["masters"]:
                _lib.say("MAST " + mast)
        return 0

    if args.cmd == "modl":
        modls, errors = modl_records(args.plugin)
        if args.json:
            print(json.dumps({"modl": [[f, t, p] for f, t, p in modls],
                              "errors": errors}, indent=2))
        else:
            for formid, rtype, modl in modls:
                _lib.say("0x%08X %-4s %s" % (formid, rtype, modl))
            for e in errors:
                _lib.say("PARSE-ERROR " + e)
            _lib.say("%d MODL records, %d parse errors" % (len(modls), len(errors)))
        return 1 if errors else 0

    # gut
    cfg = _lib.load_config(args.config)
    data_dir = Path(_lib.game_path(cfg, "dataDir", args.game)).resolve()
    out = Path(args.out).resolve()
    if str(out).lower().startswith(str(data_dir).lower()):
        raise _lib.ForensicsError(
            "refusing to write a stub under the game Data dir (%s) - forensics "
            "tools are read-only against game dirs; deploy the stub manually "
            "after backing up the original" % data_dir)
    data = Path(args.plugin).read_bytes()
    stub = gut_stub_bytes(data)
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_bytes(stub)
    _lib.say("gutted: %d -> %d bytes  (stub at %s)" % (len(data), len(stub), out))
    _lib.say("apply manually: backup the original, then copy the stub over it")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""winning_modl_sweep.py — build-wide missing-mesh sweep (winning-MODL audit).

Usage:
    py -3 C:\\Modding\\tools\\forensics\\bsa_index.py build        (first, or --index)
    py -3 C:\\Modding\\tools\\forensics\\winning_modl_sweep.py [--raw-confirm]
          [--json out.json] [--noise-list noise.txt] [--game skyrim] [--config PATH]

READ-ONLY. The only reliable missing-mesh detector on this build (wiki
concepts/skyrim-build-wide-missing-mesh-sweep): resolve every base record's
WINNING MODL after all plugin overrides (full load order, master-index FormID
mapping, rule-of-one last-wins), then check that path on disk (loose) and in
the BSA index. Mesh-level checks cannot see this class — the defect is
upstream of the mesh, in the plugin record (PG_1.esp redirected 1116 statics
to a deleted _pgpatcher_dups\\ folder; SMIM redirected cave cliffs to deleted
smimice meshes — connections/skyrim-plugin-modl-redirect-missing-mesh).

Verdict tiers (wiki reliability findings):
    HOLE      miss under a directory prefix NO BSA carries — a mod-specific
              path cannot have a BSA fallback: genuine, act on it.
    ADVISORY  miss under a vanilla-ish prefix — the BSA index provably misses
              some real vanilla entries (sack01 et al., folder-pairing quirk).
              --raw-confirm clears these via the name-table byte scan; what
              survives still needs an in-game check before repair.
    OK-LOOSE / OK-BSA  resolved.

Known noise families (wiki): vanilla dev/test meshes (gianttest, testteapot),
unowned Creation Club content, runtime spell/particle FX. Park them in a
--noise-list file (one rel path or path-prefix per line) rather than editing
this tool.
"""
import argparse
import json
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from forensics import _lib
from forensics import bsa_index
from forensics import esp_tools


def canonical_key(formid, masters, self_name):
    """(owner_file_lower, local_id). Top byte of the FormID indexes the
    plugin's master list; == len(masters) means the plugin's own record.
    NOTE 0xFE light-plugin indexing is handled per plan Task 5 Step 10."""
    idx = (formid >> 24) & 0xFF
    files = [m.lower() for m in masters] + [self_name.lower()]
    owner = files[idx] if idx < len(files) else self_name.lower()
    return owner, formid & 0x00FFFFFF


def resolve_winners(plugins):
    """plugins: ordered [(name, masters, [(formid, rtype, modl), ...])].
    Later assignment to the same canonical key wins (rule-of-one)."""
    winners = {}
    for name, masters, modls in plugins:
        for formid, _rtype, modl in modls:
            winners[canonical_key(formid, masters, name)] = (name, modl)
    return winners


def modl_candidates(modl_path):
    """MODL paths are conventionally relative to Data\\meshes\\, but recorded
    evidence quotes them both with and without the 'meshes\\' prefix — try
    both and report which resolved (verify-on-machine, plan Step 10)."""
    rel = _lib.norm_rel(modl_path)
    if rel.startswith("meshes\\"):
        return [rel]
    return ["meshes\\" + rel, rel]


def classify(candidates, data_dir, bsa_paths, bsa_dirs):
    data_dir = Path(data_dir)
    for rel in candidates:
        if (data_dir / rel).is_file():
            return "OK-LOOSE", rel
    for rel in candidates:
        if rel in bsa_paths:
            return "OK-BSA", rel
    rel = candidates[0]
    parent = rel.rsplit("\\", 1)[0] if "\\" in rel else ""
    if parent and parent not in bsa_dirs:
        return "HOLE", rel
    return "ADVISORY", rel


def run_sweep(cfg, index, game="skyrim", raw_confirm=False, noise=()):
    data_dir = Path(_lib.game_path(cfg, "dataDir", game))
    order = _lib.load_order(cfg, game)
    bsa_paths = bsa_index.all_paths(index)
    bsa_dirs = bsa_index.dir_prefixes(index)
    noise = {_lib.norm_rel(n) for n in noise}

    plugins, skipped = [], []
    for name in order:
        p = data_dir / name
        if not p.is_file():
            skipped.append(name)
            continue
        masters = _lib.tes4_header(str(p))["masters"]
        modls, errors = esp_tools.modl_records(str(p))
        for e in errors:
            _lib.say("PARSE-ERROR %s: %s" % (name, e))
        plugins.append((name, masters, modls))
    winners = resolve_winners(plugins)

    results = []
    for (owner, local), (winner, modl) in sorted(winners.items()):
        cands = modl_candidates(modl)
        verdict, rel = classify(cands, data_dir, bsa_paths, bsa_dirs)
        if verdict == "ADVISORY" and raw_confirm:
            base = rel.split("\\")[-1]
            if any(bsa_index.raw_confirm(b, base)
                   for b in sorted(data_dir.glob("*.bsa"))):
                verdict = "OK-BSA-RAW"
        if any(rel == n or rel.startswith(n) for n in noise):
            verdict = "NOISE-LISTED"
        results.append({"owner": owner, "formid": "0x%06X" % local,
                        "winner": winner, "modl": rel, "verdict": verdict})
    return {"loadOrder": order, "skippedMissingFiles": skipped,
            "results": results}


def main(argv=None):
    ap = argparse.ArgumentParser(description="winning-MODL missing-mesh sweep")
    ap.add_argument("--game", default="skyrim")
    ap.add_argument("--config", default=None)
    ap.add_argument("--index", default=None)
    ap.add_argument("--raw-confirm", action="store_true",
                    help="clear ADVISORY misses via BSA name-table byte scan (slow)")
    ap.add_argument("--json", default=None)
    ap.add_argument("--noise-list", default=None)
    args = ap.parse_args(argv)

    cfg = _lib.load_config(args.config)
    idx_path = Path(args.index) if args.index else bsa_index.default_index_path(cfg, args.game)
    if not idx_path.is_file():
        raise _lib.ForensicsError("no BSA index at %s - run bsa_index.py build first" % idx_path)
    index = bsa_index.load_index(idx_path)
    noise = []
    if args.noise_list:
        with open(args.noise_list, "r", encoding="utf-8-sig") as f:
            noise = [l.strip() for l in f if l.strip() and not l.startswith("#")]

    report = run_sweep(cfg, index, args.game, args.raw_confirm, noise)
    counts = {}
    for r in report["results"]:
        counts[r["verdict"]] = counts.get(r["verdict"], 0) + 1
    for r in report["results"]:
        if r["verdict"] == "HOLE":
            _lib.say("[HOLE]     %s %s -> %s (winner %s)"
                     % (r["owner"], r["formid"], r["modl"], r["winner"]))
    for r in report["results"]:
        if r["verdict"] == "ADVISORY":
            _lib.say("[ADVISORY] %s %s -> %s (winner %s)"
                     % (r["owner"], r["formid"], r["modl"], r["winner"]))
    for name in report["skippedMissingFiles"]:
        _lib.say("[SKIP] %s in load order but not on disk" % name)
    _lib.say("verdicts: " + ", ".join("%s=%d" % kv for kv in sorted(counts.items())))
    _lib.say("HOLEs are genuine (mod-specific path, no BSA fallback possible). "
             "ADVISORY needs --raw-confirm and/or an in-game check "
             "(BSA index misses some real vanilla entries).")
    if args.json:
        _lib.atomic_write_json(args.json, report)
        _lib.say("wrote %s" % args.json)
    return 1 if counts.get("HOLE") else 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""orphan_audit.py — loose files under Data\\ not owned by any ledger manifest.

Usage:
    py -3 C:\\Modding\\tools\\forensics\\orphan_audit.py
    py -3 ...\\orphan_audit.py --roots meshes textures interface --json out.json
    py -3 ...\\orphan_audit.py --exclude "textures\\actors\\character\\skysight"

READ-ONLY: reports orphans; quarantine stays manual (backups\\ convention).

Method (the Khajiit root-cause, memory sse-khajiit-face-investigation): vanilla
ships ZERO loose asset files — everything loose under meshes\\/textures\\ is
mod-origin by definition, and a loose file beats its BSA copy regardless of
load order. Any loose asset no manifest accounts for is an untracked override:
exactly the ~2021 khajiitfemale head textures that survived every plugin
toggle. preLedger=true (mtime before games.skyrim.ledgerEpoch, default
2026-06-19) marks the highest-suspicion class: it predates the ledger's
coverage entirely ("old timestamp != vanilla").

Default roots are meshes+textures (BSA-shadowing asset trees). Widen with
--roots when hunting elsewhere; known-intentional trees go in --exclude.
"""
import argparse
import sys
from datetime import date, datetime
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from forensics import _lib

DEFAULT_ROOTS = ("meshes", "textures")


def find_orphans(data_dir, baseline, roots, excludes):
    data_dir = Path(data_dir)
    excludes = tuple(_lib.norm_rel(e) for e in excludes)
    out = []
    for root in roots:
        rp = data_dir / root
        if not rp.is_dir():
            continue
        for ap, rel_in_root in _lib.iter_files(rp):
            rel = _lib.norm_rel(Path(root) / rel_in_root)
            if rel in baseline:
                continue
            if any(rel.startswith(e) for e in excludes):
                continue
            st = ap.stat()
            out.append({"rel": rel, "size": st.st_size,
                        "mtime": datetime.fromtimestamp(st.st_mtime).strftime("%Y-%m-%d"),
                        "preLedger": False})
    return sorted(out, key=lambda o: o["rel"])


def main(argv=None):
    ap = argparse.ArgumentParser(description="loose-file orphan audit vs ledger manifests")
    ap.add_argument("--roots", nargs="+", default=list(DEFAULT_ROOTS))
    ap.add_argument("--exclude", action="append", default=[])
    ap.add_argument("--json", default=None)
    ap.add_argument("--game", default="skyrim")
    ap.add_argument("--config", default=None)
    args = ap.parse_args(argv)

    cfg = _lib.load_config(args.config)
    data_dir = _lib.game_path(cfg, "dataDir", args.game)
    manifests = _lib.game_path(cfg, "manifestsDir", args.game)
    try:
        epoch = date.fromisoformat(_lib.game_path(cfg, "ledgerEpoch", args.game))
    except SystemExit:
        epoch = date(2026, 6, 19)

    baseline = _lib.manifest_baseline(manifests)
    orphans = find_orphans(data_dir, baseline, args.roots, args.exclude)
    for o in orphans:
        o["preLedger"] = date.fromisoformat(o["mtime"]) < epoch

    by_top = {}
    for o in orphans:
        by_top.setdefault(o["rel"].split("\\")[0], []).append(o)
    for top in sorted(by_top):
        _lib.say("== %s (%d orphans)" % (top, len(by_top[top])))
        for o in by_top[top]:
            _lib.say("  %s%-11s %8d B  %s"
                     % ("[PRE-LEDGER] " if o["preLedger"] else "",
                        o["mtime"], o["size"], o["rel"]))
    _lib.say("%d manifest-owned paths, %d orphans (%d pre-ledger)"
             % (len(baseline), len(orphans),
                sum(1 for o in orphans if o["preLedger"])))
    _lib.say("orphans are UNTRACKED overrides (loose beats BSA). Quarantine "
             "candidates manually to C:\\Modding\\skyrim-manual\\backups\\ - "
             "this tool never moves files.")
    if args.json:
        _lib.atomic_write_json(args.json, {"roots": args.roots,
                                           "orphans": orphans})
        _lib.say("wrote %s" % args.json)
    return 1 if orphans else 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
Usage:
    py -3 C:\\Modding\\tools\\forensics\\post_bake_sweep.py
    py -3 ...\\post_bake_sweep.py --since 2026-06-20 --min-cluster 5 --json out.json

READ-ONLY. Run after any PGPatcher/ParallaxGen/TexGen bake, and when an object
renders "too shiny vs its mod page" or flat-gray.

Fingerprint 1 — shared-mtime clusters: batch bakes stamp identical mtimes
(the 2026-06-27 15:23:17 batch). A cluster is a CANDIDATE bake batch, not a
verdict: archive extractions also share mtimes. Cross-read with fingerprint 2
and recency (--since), then byte-compare suspects vs their source archive —
the decisive test (memory sse-cmbake-shiny-leftovers).

Fingerprint 2 — the CM-bake placeholder cubemap: a loose .nif referencing
textures\\cubemaps\\dynamic1pxcubemap_black.dds. On this load order every such
hit was bake-modified (63/63); with ENB ComplexMaterial OFF the placeholder is
load-bearing and renders mirror-shine (wiki skyrim-cm-bake-black-cubemap-shine).

CAVEAT the sagas paid for: "not in ParallaxGen_Diff.json" proves NOTHING -
each PGPatcher run OVERWRITES the diff json; only the LAST runs are recorded.
Do not clear a mesh on diff-absence; byte-compare vs its archive.
"""
import argparse
import sys
from datetime import date, datetime
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from forensics import _lib
from forensics import nif_texrefs

FINGERPRINT_CUBEMAP = "textures\\cubemaps\\dynamic1pxcubemap_black.dds"
_NEEDLE = b"dynamic1pxcubemap_black"


def scan_meshes(meshes_dir, min_cluster=5, since=None):
    meshes_dir = Path(meshes_dir)
    by_mtime = {}
    cubemap_hits = []
    for ap, rel in _lib.iter_files(meshes_dir, exts=(".nif",)):
        st = ap.stat()
        key = int(st.st_mtime)
        entry = {"rel": rel, "size": st.st_size,
                 "mtime": datetime.fromtimestamp(st.st_mtime).strftime("%Y-%m-%d %H:%M:%S")}
        data = ap.read_bytes()
        hit = _NEEDLE in data.lower()
        if hit:
            refs = nif_texrefs.extract_texrefs(data)
            cubemap_hits.append(dict(entry, texrefs=refs))
        by_mtime.setdefault(key, []).append((entry, hit))

    clusters = []
    for key in sorted(by_mtime):
        members = by_mtime[key]
        if len(members) < min_cluster:
            continue
        mtime_str = members[0][0]["mtime"]
        if since is not None and date.fromisoformat(mtime_str[:10]) < since:
            continue
        clusters.append({
            "mtime": mtime_str,
            "count": len(members),
            "cubemapHits": sum(1 for _e, h in members if h),
            "files": [e["rel"] for e, _h in members],
        })
    clusters.sort(key=lambda c: c["count"], reverse=True)
    return {"clusters": clusters, "cubemapHits": cubemap_hits}


def main(argv=None):
    ap = argparse.ArgumentParser(description="post-bake fingerprint sweep")
    ap.add_argument("--min-cluster", type=int, default=5)
    ap.add_argument("--since", default=None, help="YYYY-MM-DD; only report clusters on/after")
    ap.add_argument("--json", default=None)
    ap.add_argument("--game", default="skyrim")
    ap.add_argument("--config", default=None)
    args = ap.parse_args(argv)

    cfg = _lib.load_config(args.config)
    meshes_dir = Path(_lib.game_path(cfg, "dataDir", args.game)) / "meshes"
    since = date.fromisoformat(args.since) if args.since else None
    report = scan_meshes(meshes_dir, args.min_cluster, since)

    _lib.say("== placeholder-cubemap hits (%d) - CM-bake leftovers, mirror-shine "
             "with CM off" % len(report["cubemapHits"]))
    for h in report["cubemapHits"]:
        _lib.say("  %s  %s" % (h["mtime"], h["rel"]))
    _lib.say("== shared-mtime clusters >= %d files (%d)"
             % (args.min_cluster, len(report["clusters"])))
    for c in report["clusters"][:40]:
        _lib.say("  %s  %5d files  %d cubemap-hits  e.g. %s"
                 % (c["mtime"], c["count"], c["cubemapHits"], c["files"][0]))
    _lib.say("clusters are CANDIDATE bake batches (archive installs share "
             "mtimes too). Decisive test = byte-compare vs source archive in "
             "Downloads. Diff-json absence proves nothing (baks only record "
             "last runs).")
    if args.json:
        _lib.atomic_write_json(args.json, report)
        _lib.say("wrote %s" % args.json)
    return 1 if report["cubemapHits"] else 0


if __name__ == "__main__":
    sys.exit(main())
```

```powershell
# Usage:
#   powershell -ExecutionPolicy Bypass -File C:\Modding\tools\forensics\dds2png.ps1 -Path <dds-file-or-dir> [-OutDir <dir>] [-Recurse]
# Prints one PNG path per converted file (feed them to image inspection).
# Evidence: dds2png inspection settled 4 corrupt-vs-clean questions (reflection-notes s6);
# texconv path/invocation precedent: C:\Modding\skyrim-manual\vram-downscale.ps1.
param(
    [Parameter(Mandatory=$true)][string]$Path,
    [string]$OutDir = "",
    [switch]$Recurse,
    [string]$Config = "C:\Modding\tools\modkit.json"
)
$ErrorActionPreference = 'Stop'

$cfg = Get-Content -Raw -LiteralPath $Config | ConvertFrom-Json
$texconv = $cfg.forensics.tools.texconv
if (-not (Test-Path -LiteralPath $texconv)) {
    throw ("texconv not found: " + $texconv + " (modkit.json forensics.tools.texconv)")
}

if ($OutDir -eq "") {
    $stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
    $OutDir = Join-Path $env:TEMP ("dds2png-" + $stamp)
}
# READ-ONLY guard: refuse to write under the configured game Data dir
$dataDir = $null
try { $dataDir = $cfg.forensics.games.skyrim.dataDir } catch {}
if ($null -ne $dataDir) {
    if ($OutDir.ToLower().StartsWith($dataDir.ToLower())) {
        throw "refusing to write PNGs under the game Data dir"
    }
}
if (-not (Test-Path -LiteralPath $OutDir)) {
    New-Item -ItemType Directory -Path $OutDir -Force | Out-Null
}

$item = Get-Item -LiteralPath $Path
if ($item.PSIsContainer) {
    if ($Recurse) {
        $files = Get-ChildItem -LiteralPath $Path -Recurse -File -Filter *.dds
    } else {
        $files = Get-ChildItem -LiteralPath $Path -File -Filter *.dds
    }
} else {
    $files = @($item)
}
if ($files.Count -eq 0) { throw ("no .dds files at " + $Path) }

$ok = 0; $fail = 0
foreach ($f in $files) {
    & $texconv -nologo -y -m 1 -ft png -o $OutDir $f.FullName *>$null
    $png = Join-Path $OutDir ($f.BaseName + ".png")
    if (Test-Path -LiteralPath $png) {
        $ok++
        Write-Output $png
    } else {
        $fail++
        Write-Output ("FAIL: " + $f.FullName)
    }
}
Write-Output ("done ok=" + $ok + " fail=" + $fail + " outdir=" + $OutDir)
if ($fail -gt 0) { exit 1 }
exit 0
```

```powershell
# vram_probe.ps1 - VRAM polling logger (GPU perf counters; AMD-safe, no nvidia-smi).
# Usage:
#   powershell -ExecutionPolicy Bypass -File C:\Modding\tools\forensics\vram_probe.ps1
#   ... -IntervalSec 4 -DurationMin 30            (bounded run)
#   ... -Samples 3                                 (smoke test)
# Output CSV matches the 2026-06-25 precedent (C:\Modding\skyrim-manual\vram-probe.csv):
#   time,dedicated_GB,shared_GB,total_GB
# Run it in the background BEFORE launching the game; a dedicated_GB pinned near
# the card's 16 GB on exterior load is the VRAM-exhaustion signature
# (vram-fix-plan.md - the probe was decisive twice).
param(
    [int]$IntervalSec = 4,
    [int]$DurationMin = 0,
    [int]$Samples = 0,
    [string]$OutCsv = "",
    [string]$Config = "C:\Modding\tools\modkit.json"
)
$ErrorActionPreference = 'Stop'

if ($OutCsv -eq "") {
    $cfg = Get-Content -Raw -LiteralPath $Config | ConvertFrom-Json
    $dir = $cfg.forensics.cacheDir
    if (-not (Test-Path -LiteralPath $dir)) {
        New-Item -ItemType Directory -Path $dir -Force | Out-Null
    }
    $stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
    $OutCsv = Join-Path $dir ("vram-probe-" + $stamp + ".csv")
}
if (-not (Test-Path -LiteralPath $OutCsv)) {
    "time,dedicated_GB,shared_GB,total_GB" | Out-File -LiteralPath $OutCsv -Encoding utf8
}

$counters = @('\GPU Adapter Memory(*)\Dedicated Usage',
              '\GPU Adapter Memory(*)\Shared Usage')
$deadline = $null
if ($DurationMin -gt 0) { $deadline = (Get-Date).AddMinutes($DurationMin) }
$taken = 0
Write-Output ("logging to " + $OutCsv + " every " + $IntervalSec + "s (Ctrl+C to stop)")

while ($true) {
    $s = Get-Counter -Counter $counters
    $ded = 0.0
    $sha = 0.0
    foreach ($cs in $s.CounterSamples) {
        if ($cs.Path -like '*dedicated*') { $ded = $ded + $cs.CookedValue }
        if ($cs.Path -like '*shared*') { $sha = $sha + $cs.CookedValue }
    }
    $dedGB = [math]::Round($ded / 1GB, 2)
    $shaGB = [math]::Round($sha / 1GB, 2)
    $totGB = [math]::Round(($ded + $sha) / 1GB, 2)
    $line = (Get-Date -Format 'HH:mm:ss') + "," + $dedGB + "," + $shaGB + "," + $totGB
    Add-Content -LiteralPath $OutCsv -Value $line
    Write-Output $line
    $taken = $taken + 1
    if ($Samples -gt 0) {
        if ($taken -ge $Samples) { break }
    }
    if ($null -ne $deadline) {
        if ((Get-Date) -gt $deadline) { break }
    }
    Start-Sleep -Seconds $IntervalSec
}
Write-Output ("done: " + $taken + " samples -> " + $OutCsv)
exit 0
```
